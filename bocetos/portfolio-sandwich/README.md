# Portfolio — concepto sándwich

- `portfolio-claro.png`: página completa en blanco cálido y burdeos.
- `portfolio-oscuro.png`: página completa en carbón, marfil y coral.
- `prompts.md`: instrucciones utilizadas para generar ambas imágenes.

Las dos láminas incluyen hero, proyectos, sobre mí y contacto. El nombre, el abanico de archivos y la especialidad forman la composición del hero. La galería muestra los cuatro proyectos con igual jerarquía. Sobre mí retoma el motivo de las hojas de trabajo, y contacto conserva cuatro accesos sociales.

Se ha aplicado la dirección `name-as-monument` de design-taste-frontend, adaptada al apilado centrado de la referencia. Se conservan las dos paletas elegidas y la cabecera flotante. No se ha generado una cara nueva ni se han inventado datos de contacto o experiencia.

Revisión visual estática: las cuatro secciones están completas; la tipografía distingue nombre, especialidad y textos; las etiquetas y las descripciones se leen; los cuatro proyectos tienen el mismo tamaño; los dos temas comparten la estructura. El aspecto preciso de las letras, los iconos y el cambio de tema es orientativo, como corresponde a un boceto rasterizado.

Estos archivos son bocetos. No modifican el código de `src/` ni la aplicación actual.
